# 上下文管理
记录和整理历史对话的模块，由于大模型和 http 服务都是无状态的，对话的历史需要由 agent 进行记录。

## 压缩截断
1. 程序化截断 — 当上一轮 token 用量接近上下文窗口上限时，ContextManager 会砍掉历史的前半部分或前 3/4，只保留最近的对话                                                                                                                               
2. Auto Condense — 对 NextGen 模型，用模型本身来压缩旧历史为摘要
